ڕێنمایی

🌍 هەموو کەس دەیبینێت: هەر کۆدێک «چالاک» بێت و پاشەکەوت بکرێت، لە هەمان ساتدا بۆ هەموو بەکارهێنەرانی سایتەکە جێبەجێ دەبێت. ئەم ئیدیتۆرە تەنها بۆ ownerـە.

📂 فایلەکانی سایت: لە لیستی فایلەکان بەشی «فایلەکانی سایت (GitHub)» هەموو فایلەکانی سایتەکەیە (services.html، admin.js، style.css...). هەر فایلێک بکەرەوە، بیگۆڕە و 💾 بکە: بۆ هەمووان جێگەی وەشانی GitHub دەگرێتەوە، بێ ئەوەی بچیتە GitHub. ⚙ = گەڕاندنەوە بۆ ئۆریجینال و مێژووی ٣٠ وەشان. ＋ ← «فایلی سایت» = پەڕە/فایلی تەواو نوێ.

🛡 پارێزراوەکان: editor.*، sw.js، site-code.js، config.js نادرێنە جێگە، تا ئیدیتۆر هەمیشە ساغ بێت. ئەگەر پەڕەیەک تێکچوو: ?safe=1 وەشانی GitHub پیشان دەدات. ئەگەر هەموو شتێک تێکچوو: ?nosw=1.

📁 فایل = پەڕە: هەر فایلێک بۆ یەک پەڕەیە (یان «هەموو پەڕەکان»). جۆر: js کۆدی کار، css دیزاین، html بەش/ناوەڕۆکی نوێ.

⚙ کۆدی JS ئەم گۆڕاوانەی هەیە: sb (Supabase)، user، profile، page.

➕ پەڕەی نوێ: لە ڕێکخستنی فایل «پەڕەی نوێ» هەڵبژێرە و ناوێک بنووسە؛ دەبێتە custom.html?p=ناو.

🛠 بەشی ئادمینی نوێ: فایلێک بۆ پەڕەی admin دروست بکە (نموونەی «بەشی ئادمینی نوێ»).

▶ پێشبینین: کۆدە پاشەکەوتنەکراوەکانیش لە پێشبینینەکە دەبینرێن، تەنها لای خۆت.

🆘 ئەگەر سایتەکە تێکچوو: ?safe=1 لە کۆتایی ئەدرەسی پەڕەکە زیاد بکە، کۆدە زیادەکان ناچالاک دەبن. ئەم ئیدیتۆرە هەرگیز کۆدی زیادە بار ناکات، بۆیە هەمیشە دەتوانی چاکی بکەیتەوە.

⌨ کورتەکان: Ctrl+S پاشەکەوت، Ctrl+F گەڕان، Ctrl+/ کۆمێنت، Ctrl+Space تەواوکردن، Ctrl+Enter پێشبینین.

🔐 ئاگاداری: کۆدی چالاک لە ڕێگەی ئینتەرنێتەوە دەخوێندرێتەوە، بۆیە هیچ پاسۆرد یان کلیلی نهێنی تێیدا مەنووسە.
